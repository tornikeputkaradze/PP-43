# წიგნების მართვის კონსოლ აპლიკაცია

BackEnd-ის პირველი ეტაპის შემაჯამებელი პროექტი — **OOP პროექტები / წიგნების მართვის კონსოლ აპლიკაცია**.

პროგრამა Python-ზეა დაწერილი და მხოლოდ იმ თემებს იყენებს, რომლებიც ლექციებზეა გავლილი (იხ. [გამოყენებული თემები](#გამოყენებული-თემები)).

## ფუნქციონალობა

- წიგნის დამატება: სათაური, ავტორი, გამოცემის წელი
- ყველა წიგნის დეტალური სიის ჩვენება
- წიგნის ძებნა სათაურის მიხედვით (რეგისტრის უგულებელყოფით, ნაწილოკრებულიც მუშაობს)
- წიგნის წაშლა სათაურის მიხედვით
- მუშაობის მაგალითი (დემო) მენიუს მე-5 პუნქტში
- მონაცემების შენახვა `books.csv`-ში — პროგრამის გათიშვის შემდეგაც რჩება

## გაშვება

```powershell
cd C:\Users\TORNIKE\PycharmProjects\BookManager
python main.py
```

გარე პაკეტები არ არის საჭირო — მხოლოდ Python-ის სტანდარტული ბიბლიოთეკა (`csv`, `os`, `abc`).

## ფაილების სტრუქტურა

| ფაილი | დანიშნულება |
|-------|--------------|
| `main.py` | კონსოლის UI, ვალიდაცია, დემო, პროგრამის შესვლის წერტილი |
| `book.py` | `LibraryItem` (ABC), `Book`, `EBook`, `book_from_row()` |
| `book_manager.py` | `BookManager` — დამატება, სია, ძებნა, წაშლა, CSV-თან მუშაობა |
| `errors.py` | საკუთარი შეცდომების იერარქია (`LibraryError` და მისი შვილები) |
| `books.csv` | მონაცემთა ფაილი (იქმნება პირველ გაშვებაზე) |

ყველა მოდულს, კლასს და მეთოდს აქვს დოკუმენტაცია (docstring) — პროექტის მოთხოვნა 2.1.7.
